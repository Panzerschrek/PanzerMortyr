This file lists game menus.

MENU.BMP - main menu.

* new game
* load game
* save game
* multiplayer
* options
* quit game


MENU_T.BMP - new game skill selection menu.
SKILL.BMP - new game skill selection menu (on polish).

* just too easy
* for kids'n grammas
* sometimes a challange
* yes! that's it!


LOADG.BMP - game loading menu.

Contains several named savegame slots.


SAVEG.BMP - game saving menu.

Contains several named savegame slots.


MENU_M2.BMP - multiplayer mode network connection menu.


MENU_M3.BMP - multiplayer mode network connection menu.


MENU_M4.BMP - multiplayer mode game parameters menu.


MENU_M5.BMP - multiplayer mode player parameters menu.


OPTION.BMP - options menu.

* customize controls
* video resolutions
* sound options
* mouse sensitivity
* hud position
* crosshair
* parental lock
* advanced options


KLAWISZ.BMP - key bindings menu.

Contains list of all controls and some input on/off options.
There are several pages fo them.


MODES.BMP - video settings menu.


Lists available video modes.


SOUND.BMP - sound settings menu.

* sound (on/off)
* background sound (on/off)
* sound volume (slider)
* background volume (slider)
* cd musik (on/off)
* mortyr's voice  (on/off)
* flip stereo (on/off)


MENU_D.BMP - adult mode menu.


ADVANC.BMP - advanced options.


HELP.BMP - credits.


SHELL.BMP - console background.
