The game archive contains files of the following types (extensions):

* ANT
* BMP - just regular Windows bitmap
* LEM
* LAM - some map data?
* OBB
* PAL
* STD - text files, mostly confings and maybe scripts. They are written in some scripting language.
* WAV - sound in well-known wave format
* WAY - presumably file with map waypoints

Maps are stored as separate files with name like ZMAP06 and extensions LAM, LEM, ANT.
Some maps have names like ZVOX or ZPOZ.

GENERIC.STD - seems to be some sort of settings file (with key bindings).
ICE.STD - lists levels with various properties including dependent resource files.
KEYS.STD - some other sort of settings file with key bindings?
TEXT.STD - HUD/Menu string tables.
TEXAB.STD - contains some texture descriptions (materials?).
