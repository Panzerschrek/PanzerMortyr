The game archive contains files of the following types (extensions):

* ANT
* BMP - just regular Windows bitmap
* LEM
* LAM - some map data?
* OBB
* PAL
* STD
* WAV - sound in well-known wave format
* WAY - presumably file with map waypoints

Maps are stored as separate files with name like ZMAP06 and extensions LAM, LEM, ANT.
Some maps have names like ZVOX or ZPOZ.
