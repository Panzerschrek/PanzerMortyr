This document lists image files which aren't textures or menu backgrounds.

* BGR.BMP - some background texture.
* MENU_A.BMP - abort this game yes/no.
* MENU_B.BMP - quit to tilte yes/no.
* MENU_KA.BMP - golden key required.
* MENU_KB.BMP - silver key required.
* MENU_KC.BMP - blue key required.
* MENU_M6.BMP - looks like unused main menu image (with red letters on red background).
* MENU_M7.BMP - looks like unused main menu image (with red letters on red background).
* MENU_M8.BMP - looks like unused main menu image (with red letters on red background).
* MENU_P.BMP - game is paused.
* MENU_S.BMP - you have found a secret place.
* MENU_W.BMP - loading.
* MENU_X.BMP - menu animated cursor frames.
* MENU_Z.BMP - menu animated cursor frames (HD).
* MORT.BMP, MORTRED.BMP, MSKIN.BMP, MSKIN_1.BMP, MSKIN_2.BMP, MSKIN_3.BMP, MSKIN_4.BMP, MSKIN_5.BMP - female multiplayer skin icons.
* SKIN.BMP, SKIN_1.BMP, SKIN_2.BMP, SKIN_3.BMP, SKIN_4.BMP, SKIN_5.BMP - male multiplayer skin icons.
* NOTE___.BMP - NOTE files, displayed on same places on some maps.
* OPTION2.BMP - atlas with elements displayed in menus - on, off, hight, medium, low, slider background, slider.
* OPTION3.BMP - atlas with screen resolutions.
* PANBL.BMP - decimal digits and minus sign, presumably used for displaying player stats.
* PANBL1.BMP - unused and outdated atlas with HUD icons and digits.
* PANEL.BMP - atlas with HUD icons and digits.
* QUIT.BMP - atlas with 8 quit texts.
* SHELL.BMP - console background.
